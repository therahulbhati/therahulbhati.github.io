Frozen wiki-faithful Markdown corpus:

  • Wikipedia REST HTML → markdownify; links, tables, references, images, navboxes and categories retained.
  • Faithful unit: one Unicode letter/mark/number run, or one visible non-space symbol.
  • Shared script-pool BPE ladders are allocated directly to minimize fertility spread.
  • 256 UTF-8 byte-fallback tokens make unseen visible characters lossless; no <unk>.
